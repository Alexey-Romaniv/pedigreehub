# Спецификация: Создание объявления

## Обзор

**Цель:** Реализовать функционал создания объявления о продаже щенка для верифицированных заводчиков.

**Маршрут:** `/breeder/listings/new`

## Требования

### 1. Доступ

- ✅ Только для авторизованных пользователей с ролью `breeder`
- ✅ Только для верифицированных заводчиков (`verification.status === 'verified'`)
- ❌ Если заводчик не верифицирован → показать сообщение с предложением загрузить документы

### 2. Структура формы (Wizard, 4 шага)

#### Шаг 1: Основная информация

**Поля:**
- `title` (String, обязательное) — Заголовок объявления
  - Минимум 10 символов, максимум 100
  - Пример: "Szczenięta Golden Retriever - złote, zdrowe"
  
- `breed` (ObjectId, обязательное) — Порода
  - Выбор из каталога пород FCI (combobox с поиском по польскому и английскому названию)
  - Каталог досеивается при старте сервера (`breeds.data.ts`, upsert по имени)
  - Несовпадение со списком пород заводчика (`breeder.breeds`) **не блокирует** отправку — расхождение отображается админу в `autoChecks.dataConsistency` при модерации
  
- `birthDate` (Date, обязательное) — Дата рождения щенка
  - Не может быть в будущем
  - Минимум 6 недель от текущей даты (закон о продаже щенков)
  
- `gender` (String, обязательное) — Пол
  - Radio buttons: "male" | "female"
  
- `color` (String, обязательное) — Окрас
  - Text input с автодополнением (можно предложить популярные окрасы для породы)
  
- `puppyName` (String, опциональное) — Имя щенка
  - Если не указано, будет "Szczenię" или "Szczenięta"
  
- `price` (Number, обязательное) — Цена
  - Положительное число
  - Минимум 100 PLN
  
- `currency` (String, обязательное) — Валюта
  - Select: "PLN" | "EUR"
  - По умолчанию: "PLN"

**Валидация:**
- Все обязательные поля должны быть заполнены
- Дата рождения должна быть валидной
- Цена должна быть положительным числом

**UI:**
- Форма с полями
- Кнопка "Далее" (только если форма валидна)
- Индикатор прогресса (1/4)

---

#### Шаг 2: Информация о родителях

**Поля для отца:**
- `father.name` (String, обязательное) — Имя отца
- `father.pedigreeNumber` (String, опциональное) — Номер родословной
  - Свободный формат (буквы, цифры, `. - /`, 2–30 знаков): родители могут иметь родословную не только ZKwP, но и других организаций FCI (VDH, ÖKV и т.д.). Соответствие документу проверяет админ
- `father.titles` (String[], опциональное) — Титулы (массив строк)
  - Можно добавить несколько через "+ Добавить титул"
  - Примеры: "Champion Polski", "Champion Międzynarodowy", "Winner"
- `father.photo` (File, опциональное) — Фото отца
  - Одно изображение, до 5MB
  - Форматы: JPG, PNG, WebP

**Поля для матери:**
- `mother.name` (String, обязательное) — Имя матери
- `mother.pedigreeNumber` (String, опциональное) — Номер родословной
- `mother.titles` (String[], опциональное) — Титулы
- `mother.photo` (File, опциональное) — Фото матери

**UI:**
- Две секции: "Ojciec" и "Matka"
- Для каждого родителя: поля ввода, кнопка загрузки фото
- Превью загруженных фото
- Кнопки "Назад" и "Далее"
- Индикатор прогресса (2/4)

**Валидация:**
- Имена родителей обязательны
- Фото должны быть валидными изображениями

---

#### Шаг 3: Документы щенка

**Поля:**
- `microchipNumber` (String, обязательное) — Номер микрочипа
  - Ровно 15 цифр
  - Формат ISO 11784/11785
  - Валидация: первые 3 цифры — код страны ISO 3166 (616 = Польша, 276 = Германия, 203 = Чехия и т.д. — щенок может быть чипован за границей) или код производителя чипа (900–998). Список кодов: `MICROCHIP_COUNTRY_CODES` в `listing.validation.ts` (продублирован на фронте в `CreateListingWizard.tsx`)
  - Маска ввода: `616***********` (показывать только последние 3 цифры для безопасности)
  - **Примечание:** Проверяется только формат, не подлинность в национальной БД (см. [VERIFICATION-STRATEGY.md](./VERIFICATION-STRATEGY.md))
  
- `hasPedigree` (Boolean) — Есть родословная
  - Checkbox
  - Если отмечено → показать поле загрузки `pedigreeDocument`
  
- `pedigreeDocument` (File, опциональное) — Документ родословной
  - Загружается только если `hasPedigree === true`
  - PDF, JPG, PNG, WebP, до 10MB
  
- `hasVetPassport` (Boolean) — Есть ветпаспорт
  - Checkbox
  - Если отмечено → показать поле загрузки `vetPassportDocument`
  
- `vetPassportDocument` (File, опциональное) — Ветпаспорт
  - Загружается только если `hasVetPassport === true`
  - PDF, JPG, PNG, WebP, до 10MB
  
- `hasMetric` (Boolean) — Есть метрика
  - Checkbox
  - Если отмечено → показать поле загрузки `metricDocument`
  
- `metricDocument` (File, опциональное) — Метрика щенка
  - Загружается только если `hasMetric === true`
  - PDF, JPG, PNG, WebP, до 10MB

**UI:**
- Секция "Номер микрочипа" с валидацией
- Секции для каждого типа документа с чекбоксами
- Компонент загрузки файла (drag & drop или кнопка)
- Превью загруженных документов
- Кнопки "Назад" и "Далее"
- Индикатор прогресса (3/4)

**Валидация:**
- Микрочип обязателен и должен быть валидным (формат ISO 11784/11785)
- Проверка уникальности микрочипа в нашей БД (не используется в других объявлениях)
- Если отмечен чекбокс документа, файл должен быть загружен
- **Важно:** Подлинность документов проверяется администратором вручную (см. [VERIFICATION-STRATEGY.md](./VERIFICATION-STRATEGY.md))

#### Шаг 4: Фотографии и описание

**Поля:**
- `photos` (File[], обязательное) — Фотографии щенка
  - Минимум 3 фотографии
  - Максимум 10 фотографий
  - Каждая до 5MB
  - Форматы: JPG, PNG, WebP
  - Первая фотография — главная (будет использоваться в каталоге)
  
- `videos` (String[], опциональное) — Видео
  - Массив URL (YouTube, Vimeo)
  - Валидация URL
  - Максимум 3 видео
  
- `description` (String, обязательное) — Описание
  - Минимум 100 символов
  - Максимум 5000 символов
  - Rich text editor (опционально, можно начать с простого textarea)
  - Подсказки: описать характер, особенности, здоровье, условия содержания

**UI:**
- Галерея загрузки фото (drag & drop)
  - Показывать превью загруженных фото
  - Возможность удалить фото
  - Возможность изменить порядок (первое = главное)
  - Счетчик: "3/10 фотографий"
  
- Секция для видео
  - Поле ввода URL
  - Кнопка "Добавить видео"
  - Список добавленных видео с возможностью удаления
  
- Textarea для описания
  - Счетчик символов
  - Подсказка с примерами
  
- Кнопки "Назад" и "Предпросмотр"
- Индикатор прогресса (4/4)

**Валидация:**
- Минимум 3 фото
- Описание минимум 100 символов
- Видео URL должны быть валидными

---

### 4. Сохранение объявления

**Статусы:**
- `draft` — Черновик (можно редактировать, не видно в каталоге)
- `pending` — Ожидает модерации (отправлено на проверку админу)
- `active` — Активно (одобрено админом, видно в каталоге)
- `rejected` — Отклонено (админ отклонил, можно редактировать и отправить заново)
- `sold` — Продано (заводчик отметил как проданное)
- `reserved` — Зарезервировано
- `archived` — В архиве

**При создании:**
- Если "Сохранить как черновик" → `status: 'draft'`
- Если "Отправить на модерацию" → `status: 'pending'`

**После сохранения:**
- Редирект на `/breeder/listings` (список объявлений)
- Toast уведомление: "Объявление сохранено" / "Объявление отправлено на модерацию"

## Backend API

### Создание объявления

```http
POST /api/listings
Authorization: Bearer <access_token>
Content-Type: multipart/form-data
```

**Body:**
- Все поля из формы (JSON)
- Файлы: `photos[]`, `fatherPhoto`, `motherPhoto`, `pedigreeDocument`, `vetPassportDocument`, `metricDocument`

**Response (201):**
```json
{
  "success": true,
  "data": {
    "_id": "listing_id",
    "status": "pending",
    "verificationStatus": "pending",
    "createdAt": "2024-11-01T10:00:00Z"
  }
}
```

**Ошибки:**
- `403` — Заводчик не верифицирован
- `400` — Ошибка валидации
- `422` — Неверный формат данных
