# Маршруты приложения (Routes)

## Обзор ролей

В системе 3 роли пользователей:

| Роль | Описание | Редирект после логина |
|------|----------|----------------------|
| `user` | Покупатель (обычный пользователь) | `/profile` |
| `breeder` | Заводчик (продавец щенков) | `/breeder/dashboard` |
| `admin` | Администратор платформы (только модерация и верификация) | `/admin/verification` |

---

## Структура маршрутов

### 📍 Публичные страницы

Доступны **всем** пользователям (гостям и авторизованным).

| Путь | Компонент | Статус | Описание |
|------|-----------|--------|----------|
| `/` | `HomePage` | ✅ Готово | Главная страница |
| `/catalog` | `CatalogPage` | ✅ Готово | Каталог объявлений с фильтрами |
| `/puppy/:id` | — | 🔄 В разработке | Детальная страница объявления |
| `/breeder/:id` | — | 🔄 В разработке | Публичный профиль заводчика |

---

### 🔓 Гостевые страницы

Доступны **только неавторизованным** пользователям.  
Авторизованные автоматически редиректятся на свою панель.

| Путь | Компонент | Статус | Описание |
|------|-----------|--------|----------|
| `/login` | `LoginPage` | ✅ Готово | Вход в систему |
| `/register` | `RegisterPage` | ✅ Готово | Регистрация покупателя |
| `/register/breeder` | `BreederRegisterPage` | ✅ Готово | Регистрация заводчика (wizard) |
| `/forgot-password` | — | 🔄 В разработке | Восстановление пароля |

---

### 👤 Панель покупателя (role: `user`)

Личный кабинет обычного пользователя.

| Путь | Компонент | Статус | Описание |
|------|-----------|--------|----------|
| `/profile` | `ProfilePage` | ✅ Готово | Мой профиль |
| `/profile/favorites` | — | 🔄 В разработке | Избранные объявления |
| `/profile/inquiries` | — | 🔄 В разработке | Мои запросы заводчикам |
| `/profile/settings` | `SettingsPage` | ✅ Готово | Настройки аккаунта: данные, фото профиля, смена пароля |

**Возможности покупателя:**
- Просмотр каталога щенков
- Добавление в избранное
- Отправка запросов заводчикам
- Переписка с заводчиками
- Оставление отзывов после покупки

---

### 🐕 Панель заводчика (role: `breeder`)

Управление питомником и объявлениями.

| Путь | Компонент | Статус | Описание |
|------|-----------|--------|----------|
| `/breeder` | — | ↪️ Redirect | Редирект на `/breeder/dashboard` |
| `/breeder/dashboard` | `BreederDashboardPage` | ✅ Готово | Дашборд заводчика |
| `/breeder/documents` | `BreederDocumentsPage` | ✅ Готово | Документы для верификации |
| `/breeder/listings` | — | 🔄 В разработке | Мои объявления |
| `/breeder/listings/new` | — | 🔄 В разработке | Создание объявления |
| `/breeder/inquiries` | — | 🔄 В разработке | Входящие запросы от покупателей |

**Возможности заводчика:**
- Загрузка документов для верификации
- Создание и управление объявлениями
- Ответы на запросы покупателей
- Просмотр статистики

---

### ⚙️ Админ-панель (role: `admin`)

Верификация, модерация, управление платформой.

| Путь | Компонент | Статус | Описание |
|------|-----------|--------|----------|
| `/admin` | — | ↪️ Redirect | Редирект на `/admin/verification` |
| `/admin/verification` | `AdminVerificationPage` | ✅ Готово | Верификация заводчиков |
| `/admin/dashboard` | — | 🔄 В разработке | Статистика платформы |
| `/admin/users` | — | 🔄 В разработке | Управление пользователями |
| `/admin/moderation` | — | 🔄 В разработке | Модерация объявлений |

**Возможности администратора:**
- Верификация документов заводчиков
- Модерация объявлений
- Управление пользователями
- Просмотр статистики платформы

**Ограничения администратора:**
- ❌ Не может создавать объявления
- ❌ Не может управлять объявлениями как заводчик
- ❌ Нет доступа к панели заводчика (`/breeder/*`)

## Система лейаутов

Каждая роль имеет свой лейаут с навигацией:

| Лейаут | Роли | Описание |
|--------|------|----------|
| `MainLayout` | Все | Публичный сайт с хедером и футером |
| `AuthLayout` | Гости | Формы входа/регистрации |
| `BreederAuthLayout` | Гости | Регистрация заводчика (wizard) |
| `UserLayout` | user, breeder, admin | Личный кабинет покупателя с сайдбаром |
| `BreederLayout` | breeder | Панель заводчика с сайдбаром |
| `AdminLayout` | admin | Админ-панель с темным сайдбаром |

### Структура лейаутов

```
frontend/src/app/layouts/
├── MainLayout.tsx        # Публичный сайт
├── AuthLayout.tsx        # Авторизация (login/register)
├── BreederAuthLayout.tsx # Регистрация заводчика
├── UserLayout.tsx        # Личный кабинет покупателя
├── BreederLayout.tsx     # Панель заводчика
└── AdminLayout.tsx       # Админ-панель
```

## Логика защиты маршрутов

### ProtectedRoute

```tsx
<ProtectedRoute allowedRoles={['breeder']} />
```

- Если **не авторизован** → редирект на `/login`
- Если роль не в `allowedRoles` → редирект на `/`
- Если `allowedRoles` не указан → доступ всем авторизованным

**Примеры использования:**
- `allowedRoles={['user', 'breeder', 'admin']}` — доступ для всех ролей (например, профиль пользователя)
- `allowedRoles={['breeder']}` — только для заводчиков (панель заводчика)
- `allowedRoles={['admin']}` — только для администраторов (админ-панель)

### GuestRoute

```tsx
<GuestRoute />
```

Если **авторизован** → редирект в зависимости от роли:
- `admin` → `/admin/verification`
- `breeder` → `/breeder/dashboard`
- `user` → `/profile`

## Backend API роуты

Все API эндпоинты находятся под `/api`:

| Модуль | Базовый путь | Описание |
|--------|--------------|----------|
| Auth | `/api/auth/*` | Регистрация, логин, токены |
| Breeders | `/api/breeders/*` | Профили заводчиков |
| Documents | `/api/documents/*` | Загрузка документов |
| Listings | `/api/listings/*` | Объявления |
| Inquiries | `/api/inquiries/*` | Запросы на покупку |
| Reviews | `/api/reviews/*` | Отзывы |
| Admin | `/api/admin/*` | Функции администратора |

Подробнее см. [API.md](./API.md)
