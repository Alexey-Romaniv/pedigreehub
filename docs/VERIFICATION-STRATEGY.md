# Стратегия верификации документов животных

## Проблема

**Отсутствие бесплатных API/БД для автоматической проверки:**
- ❌ Нет бесплатного API для проверки микрочипов
- ❌ Нет бесплатного API для проверки родословных ZKwP/FCI
- ❌ Нет бесплатного API для проверки ветпаспортов
- ❌ Базы данных ZKwP/FCI не предоставляют публичный доступ

> **Обновление 2026-08-20:** у ZKwP есть публичная веб-форма проверки микрочипа
> (https://zkwp.pl/baza_chip.php) — официального API нет, но форма проверяется
> программно (best-effort скрейпинг). Интегрирована как дополнительный autoCheck —
> см. раздел «Проверка чипа в базе ZKwP» ниже и `docs/ZKWP-INTEGRATION-SPEC.md`.

## Решение для MVP: Многоуровневая верификация

### Уровень 1: Автоматическая валидация формата

**Что проверяем автоматически:**

#### Микрочип
- ✅ Формат ISO 11784/11785 (15 цифр)
- ✅ Код страны (первые 3 цифры: 616 = Польша)
- ✅ Структура номера (код производителя + уникальный номер)
- ✅ Уникальность в нашей БД (не используется в других объявлениях)

**Что НЕ проверяем:**
- ❌ Существование чипа в коммерческих базах (Safe-Animal, Europetnet — нет API)

#### Проверка чипа в базе ZKwP (реализовано 2026-08-20)

`zkwp.service.ts` при отправке объявления на модерацию проверяет чип в публичной
базе ZKwP (собаки с выданными metrykami + импорты). Результат — в
`autoChecks.zkwpChip`:
- **found** — собака зарегистрирована в ZKwP (сильный позитивный сигнал);
  админ видит kличку, przydomek, пол, дату рождения, oddział + флаг
  `birthDateMatches` (сверка с датой в объявлении); публично отдаётся только
  флаг `zkwpVerified` (печать «Zweryfikowano w bazie ZKwP» на карточке щенка)
- **not_found** — нейтральный сигнал: щенок мог ещё не попасть в базу;
  админ проверяет metrykę вручную (жёлтая подсказка, не ошибка)
- **unavailable** — база недоступна; никогда не блокирует отправку

Принципы: best-effort (сбои не мешают модерации), кэш положительного результата
по `checkedChip`, запрос только при отправке на модерацию, kill-switch
`ZKWP_CHECK_ENABLED=false`. Детали: `docs/ZKWP-INTEGRATION-SPEC.md`.

**Реализация:**
```typescript
function validateMicrochipFormat(chip: string): ValidationResult {
  // Проверка формата
  if (!/^\d{15}$/.test(chip)) {
    return { valid: false, error: 'Микрочип должен содержать 15 цифр' }
  }
  
  // Проверка кода страны
  const countryCode = chip.substring(0, 3)
  const validCountryCodes = ['616'] // Польша, можно добавить другие
  if (!validCountryCodes.includes(countryCode)) {
    return { valid: false, error: 'Неверный код страны' }
  }
  
  // Проверка уникальности в нашей БД
  const exists = await Listing.findOne({ microchipNumber: chip })
  if (exists) {
    return { valid: false, error: 'Этот микрочип уже используется' }
  }
  
  return { valid: true }
}
```

#### Родословная ZKwP
- ✅ Формат номера родословной (например: `PKR.VIII-12345`)
- ✅ Соответствие формату ZKwP
- ✅ Проверка, что номер не используется в других объявлениях

**Реализация:**
```typescript
function validatePedigreeNumber(number: string): ValidationResult {
  // Формат: PKR.VIII-12345 или XII-1234/56
  const zkwpPattern = /^(PKR\.)?[IVX]+-\d+(\/\d+)?$/
  if (!zkwpPattern.test(number)) {
    return { valid: false, error: 'Неверный формат номера родословной ZKwP' }
  }
  
  return { valid: true }
}
```

#### Ветпаспорт
- ✅ Формат документа (визуальная проверка структуры)
- ✅ Наличие обязательных полей на фото/скане
- ✅ Качество изображения (читаемость)

### Уровень 2: Визуальная проверка администратором

**Что проверяет админ вручную:**

1. **Микрочип:**
   - Соответствие номера на документе номеру в объявлении
   - Наличие документа с микрочипом (ветпаспорт, сертификат)
   - Читаемость документа

2. **Родословная:**
   - Подлинность документа (визуальная проверка)
   - Соответствие данных (порода, дата рождения, родители)
   - Наличие печатей и подписей ZKwP
   - Соответствие номера формату ZKwP

3. **Ветпаспорт:**
   - Подлинность документа
   - Наличие всех обязательных отметок
   - Соответствие данных щенку
   - Вакцинации (актуальность)

4. **Метрика:**
   - Подлинность документа
   - Соответствие данных

5. **Фото родителей:**
   - Соответствие описанию
   - Качество фото

**Процесс модерации:**
```
Объявление создано → Статус: pending
         ↓
Админ открывает объявление
         ↓
Проверяет документы визуально
         ↓
    ┌────┴────┐
    ↓         ↓
Одобрено  Отклонено
    ↓         ↓
 active   rejected
         (с причиной)
```

### Уровень 3: Проверка соответствия данных

**Автоматические проверки:**

1. **Соответствие породы:**
   - Порода в объявлении должна быть в списке пород заводчика
   - Порода родителей должна соответствовать породе щенка

2. **Соответствие дат:**
   - Дата рождения щенка должна быть логичной (не в будущем, минимум 6 недель)
   - Возраст родителей должен быть достаточным для разведения

3. **Соответствие документов:**
   - Если указан номер родословной отца/матери, он должен быть в формате ZKwP
   - Номер микрочипа должен соответствовать формату ISO

## Реализация в системе

### Модель Listing

```typescript
interface Listing {
  // ... другие поля
  
  // Верификация
  verificationStatus: 'pending' | 'verified' | 'rejected'
  verificationNote?: string  // Причина отклонения
  verifiedBy?: ObjectId      // Кто проверил (admin)
  verifiedAt?: Date
  
  // Автоматические проверки
  autoChecks: {
    microchipFormatValid: boolean
    pedigreeFormatValid: boolean
    documentsUploaded: boolean
    dataConsistency: boolean
    passedAt: Date
  }
}
```

### Процесс создания объявления

```typescript
async function createListing(data: CreateListingData) {
  // 1. Автоматическая валидация формата
  const microchipCheck = validateMicrochipFormat(data.microchipNumber)
  const pedigreeCheck = validatePedigreeNumber(data.father.pedigreeNumber)
  
  // 2. Проверка уникальности микрочипа
  const chipExists = await checkMicrochipUniqueness(data.microchipNumber)
  
  // 3. Сохранение с результатами автоматических проверок
  const listing = await Listing.create({
    ...data,
    status: 'pending',
    verificationStatus: 'pending',
    autoChecks: {
      microchipFormatValid: microchipCheck.valid,
      pedigreeFormatValid: pedigreeCheck.valid,
      documentsUploaded: !!data.pedigreeDocument,
      dataConsistency: checkDataConsistency(data),
      passedAt: new Date()
    }
  })
  
  return listing
}
```
