# PedigreeHub — Платформа для заводчиков породистых собак

## Описание проекта

**PedigreeHub** — специализированная веб-платформа для легальной продажи породистых собак с полной документацией. Платформа решает проблему мошенничества на общих площадках объявлений (OLX, Allegro) путём верификации заводчиков и документов животных.

## Проблема

В Польше продажа собак регулируется законодательством:
- Запрещена нелегальная продажа без зарегистрированного питомника
- Обязательны: ветеринарный паспорт, родословная, микрочип
- Существующие площадки (OLX) не обеспечивают верификацию продавцов и животных

## Решение

Специализированная платформа с системой верификации:
- Только зарегистрированные заводчики могут публиковать объявления
- Проверка документов животных администратором
- Прозрачная система отзывов и рейтингов

## Ключевые функции

### Для покупателей
- Каталог щенков с расширенной фильтрацией (порода, регион, цена, возраст)
- Детальные карточки объявлений с фото, документами, информацией о родителях
- Верифицированные заводчики с рейтингами
- Система запросов на покупку

### Для заводчиков
- Регистрация и верификация питомника
- Создание объявлений с загрузкой документов
- Управление запросами от покупателей
- Статистика просмотров и запросов

### Для администраторов
- Верификация новых заводчиков
- Модерация объявлений
- Управление пользователями
- Аналитика платформы

## Роли пользователей

| Роль | Описание |
|------|----------|
| **Гость** | Просмотр каталога, фильтрация, просмотр профилей |
| **Покупатель (user)** | + Отправка запросов на покупку, переписка с заводчиками, отзывы |
| **Заводчик (breeder)** | + Создание объявлений, управление профилем питомника |
| **Администратор (admin)** | + Верификация, модерация, управление системой |

## Бизнес-модель

**Важно:** Платформа — это доска объявлений с верификацией, а НЕ маркетплейс.

- Платформа **НЕ обрабатывает платежи**
- Сделки происходят **напрямую между покупателем и заводчиком**
- Платформа обеспечивает:
  - ✅ Верификацию легальных заводчиков
  - ✅ Проверку документов щенков
  - ✅ Безопасную переписку
  - ✅ Систему отзывов и рейтингов

## Быстрый старт

```bash
# Клонирование репозитория
git clone <repository-url>
cd pedigreehub

# Запуск Backend
cd backend
yarn install
yarn dev

# Запуск Frontend (в отдельном терминале)
cd frontend
yarn install
yarn dev
```
