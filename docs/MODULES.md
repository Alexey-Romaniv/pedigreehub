# Описание модулей

## Обзор

Система разделена на модули по функциональному признаку. Каждый модуль отвечает за определённую область бизнес-логики.

---

## Backend модули

### 1. Auth (Аутентификация)

**Ответственность:** Регистрация, авторизация, управление сессиями

**Файлы:**
```
modules/auth/
├── auth.controller.ts
├── auth.service.ts
├── auth.routes.ts
├── auth.validation.ts
└── auth.types.ts
```

**Функции:**
- Регистрация пользователя
- Регистрация заводчика (расширенная)
- Вход в систему (JWT)
- Выход из системы
- Обновление токена
- Сброс пароля
- Подтверждение email

**Эндпоинты:**
| Метод | URL | Описание |
|-------|-----|----------|
| POST | /api/auth/register | Регистрация пользователя |
| POST | /api/auth/register/breeder | Регистрация заводчика |
| POST | /api/auth/login | Вход |
| POST | /api/auth/logout | Выход |
| POST | /api/auth/refresh | Обновить токен |
| POST | /api/auth/forgot-password | Запрос сброса пароля |
| POST | /api/auth/reset-password | Сброс пароля |
| GET | /api/auth/verify-email/:token | Подтверждение email |
| GET | /api/auth/me | Текущий пользователь |

### 6. Documents (Документы)

**Ответственность:** Загрузка, хранение и верификация документов

**Функции:**
- Загрузка файлов (Multer + Cloudinary)
- Множественная загрузка для определенных типов документов
- Верификация документов администратором
- Автоматическое обновление статуса верификации заводчика
- Удаление файлов из Cloudinary

**Типы документов:**
- `zkwp_certificate` — Свидетельство ZKwP (обязательный, одиночная загрузка)
- `identity` — Документ личности (одиночная загрузка)
- `award` — Дипломы/награды (множественная загрузка)
- `pedigree` — Родословные собак (множественная загрузка)
- `kennel_photo` — Фото питомника (множественная загрузка)
- `puppy_photo` — Фото щенка
- `vet_passport` — Ветпаспорт
- `metric` — Метрика щенка
- `other` — Прочее

**Эндпоинты:**
| Метод | URL | Описание |
|-------|-----|----------|
| POST | /api/documents/upload | Загрузить файл (можно несколько для award/pedigree/kennel_photo) |
| GET | /api/documents/my | Получить мои документы (опционально фильтр по типу) |
| GET | /api/documents/:id | Получить документ |
| DELETE | /api/documents/:id | Удалить документ |

**Админ эндпоинты:**
| Метод | URL | Описание |
|-------|-----|----------|
| GET | /api/admin/documents/pending | Список документов на модерацию |
| POST | /api/admin/documents/:id/approve | Одобрить документ |
| POST | /api/admin/documents/:id/reject | Отклонить документ (с причиной) |

**Особенности:**
- При одобрении документа типа `award` автоматически создается запись в `breeder.verification.awards[]`
- При одобрении документа типа `pedigree` автоматически создается запись в `breeder.verification.breedingDogs[]`
- При удалении одобренного документа автоматически удаляются связанные записи из профиля заводчика

### 7. Inquiries (Запросы на покупку)

**Ответственность:** Запросы на покупку, переписка между покупателем и заводчиком

**Кто использует:**
- **Покупатель (user):** отправляет запросы, ведёт переписку
- **Заводчик (breeder):** получает и обрабатывает запросы

**Функции:**
- Отправка запроса на покупку
- Список запросов (для покупателя и заводчика)
- Переписка в рамках запроса
- Изменение статуса (прочитан, в обработке, закрыт)
- Уведомления о новых сообщениях

**Статусы запроса:**
- `new` — новый (ещё не прочитан заводчиком)
- `read` — прочитан
- `in_progress` — ведётся переписка
- `closed` — закрыт
- `purchased` — сделка состоялась (можно оставить отзыв)

**Эндпоинты:**
| Метод | URL | Описание |
|-------|-----|----------|
| GET | /api/inquiries | Мои запросы (для покупателя) |
| GET | /api/inquiries/received | Входящие запросы (для заводчика) |
| GET | /api/inquiries/:id | Детали запроса с перепиской |
| POST | /api/inquiries | Отправить запрос на покупку |
| POST | /api/inquiries/:id/reply | Ответить в переписке |
| PATCH | /api/inquiries/:id/status | Изменить статус |
| POST | /api/inquiries/:id/mark-purchased | Отметить как "куплено" |
