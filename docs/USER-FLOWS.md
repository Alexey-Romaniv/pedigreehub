# Пользовательские сценарии (User Flows)

## Сценарий 1: Регистрация заводчика

### Описание
Заводчик регистрируется на платформе, предоставляет данные о питомнике и документы для верификации.

### Шаги

```
[Главная страница]
        │
        ▼
[Кнопка "Зарегистрироваться как заводчик"]
        │
        ▼
┌─────────────────────────────────────┐
│ ЭТАП 1: Личные данные               │
│                                     │
│ • Имя *                             │
│ • Фамилия *                         │
│ • Email *                           │
│ • Телефон *                         │
│ • Пароль *                          │
│ • Подтверждение пароля *            │
│                                     │
│ [Далее]                             │
└─────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────┐
│ ЭТАП 2: Данные питомника            │
│                                     │
│ • Название питомника *              │
│ • Регистрационный номер ZKwP/FCI *  │
│ • Воеводство * (выбор из списка)    │
│ • Город *                           │
│ • Адрес                             │
│ • Описание питомника *              │
│ • Сайт                              │
│ • Facebook                          │
│ • Instagram                         │
│ • Породы * (множественный выбор)    │
│                                     │
│ [Назад] [Далее]                     │
└─────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────┐
│ ЭТАП 3: Документы для верификации   │
│                                     │
│ • Свидетельство о регистрации       │
│   питомника ZKwP * [Загрузить]      │
│                                     │
│ • Документ удостоверяющий           │
│   личность * [Загрузить]            │
│                                     │
│ [Назад] [Зарегистрироваться]        │
└─────────────────────────────────────┘
        │
        ▼
[Письмо с подтверждением на email]
        │
        ▼
[Клик по ссылке → Email подтверждён]
        │
        ▼
[Статус: Ожидание верификации]
        │
        ▼
[Администратор проверяет документы]
        │

        │
        └──→ [Отклонено] → Уведомление с причиной
```

### Валидация

| Поле | Правила |
|------|---------|
| Email | Уникальный, валидный формат |
| Пароль | Минимум 8 символов, буквы + цифры |
| Телефон | Польский формат (+48...) |
| Номер ZKwP | Формат согласно ZKwP |
| Файлы | PDF/JPG/PNG, максимум 5MB |

## Сценарий 5: Процесс покупки (полный цикл)

### Описание
Покупатель — это обычный пользователь (физическое лицо), который хочет приобрести породистого щенка. Платформа НЕ обрабатывает платежи напрямую — она связывает покупателя с заводчиком, а сделка происходит вне платформы.

### Кто такой покупатель?

| Характеристика | Описание |
|----------------|----------|
| **Роль** | Обычный пользователь (user) |
| **Регистрация** | Простая (email + пароль) |
| **Верификация** | Не требуется |
| **Возможности** | Просмотр каталога, отправка запросов, отзывы |

   - Верификацию заводчика (легальный питомник)

   - Систему отзывов для репутации
