# PedigreeHub

Платформа для заводчиков породистых собак с верификацией.

Дипломный проект: легальная продажа породистых собак в Польше с проверкой
заводчиков и документов животных.

## Стек

- Backend: Express + TypeScript + MongoDB (Mongoose)
- Frontend: React + TypeScript + Vite (будет позже)

## Запуск backend

```bash
cd backend
cp env.example .env
yarn install
yarn dev
```

Сервер поднимается на http://localhost:3000
